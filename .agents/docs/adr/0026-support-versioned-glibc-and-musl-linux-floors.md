# Support versioned glibc and musl Linux floors

FSharp2 ships `linux-x64`, `linux-arm64`, `linux-musl-x64`, and `linux-musl-arm64` compiler hosts in addition to the required Windows and macOS hosts. The glibc artifacts require no symbol newer than `GLIBC_2.27` and execute natively on RHEL 8 x64/Arm64 as their minimum certified deployment floor; the musl artifacts use a musl 1.2.3 sysroot and execute natively on Alpine 3.21 x64/Arm64. Each release records and verifies ELF architecture, interpreter, native dependencies, symbol requirements, toolchain/sysroot, image digest, ICU strategy, real Compiler Target Invocation behavior, persistent-service behavior, and portable-cache behavior on real target hardware; QEMU does not count. FSharp2 claims no universal numeric kernel floor and supports only publisher-supported distro lines in the versioned [.NET 10 matrix](../research/linux-runtime-and-deployment-compatibility-floors.md), with rebuild/redeployment required for adopted .NET or native security updates.
