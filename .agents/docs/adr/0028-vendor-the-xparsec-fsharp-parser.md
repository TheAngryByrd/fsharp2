# Vendor the XParsec F# parser

FSharp2 vendors the XParsec F# parser as owned source: projects `XParsec` and `XParsec.FSharp` from `https://github.com/roboz0r/XParsec`, branch `semantic-analysis`, commit `a8f12cd`, under the MIT license (Copyright (c) 2025 Robert Lenders). The semantic analysis and code generation projects of that branch are not vendored. This decision amends ADR 0001: production code stays independent of `dotnet/fsharp`, and FSharp2 can vendor third-party source under a license that is compatible with this repository. This decision replaces the "no dependency" decision of the [XParsec parser reference](../research/xparsec-parser-reference-2026.md). A measured evaluation on 2026-10-01 parsed 264 `dotnet/fsharp` source files with 0 crashes and 259 clean results. It also found no FS diagnostic codes, silent accepts of input that the Compatibility Oracle rejects, a NativeAOT startup failure, and a stack overflow at about 300 nested parentheses.

The vendored code must satisfy four conditions. The MIT copyright and permission notice stay with the source, and `THIRD-PARTY-NOTICES.md` names the source repository, branch, and commit. The vendored projects publish under NativeAOT with no trim or AOT warning from their code, as ADR 0002 requires, and nesting that would overflow the stack reports a diagnostic. No tree from the vendored parser reaches the compile path unless a comparison with FCS trees and Compatibility Oracle diagnostics makes each accepted form exact, and every other form reports an explicit diagnostic such as `FSC2P1001` (ADR 0010 continues to forbid fallback to the official compiler). FSharp2 owns and changes the vendored code in this repository. Changes stay close to the source where possible, so that later upstream changes can be compared, but upstream compatibility is not a requirement.
