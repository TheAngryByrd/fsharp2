# Keep the F# metadata harness inspector envelope-only

The differential harness will use an independently authored, test-only `System.Reflection.Metadata`/Deflate inspector for exact F# resource-envelope structure, while four-way F# producer/consumer behavior and the Compatibility Oracle remain the semantic authority. A deeper private-pickle decoder may provide versioned diagnostic fingerprints but cannot decide compatibility or validate production cache reuse. FSharp2's NativeAOT production importer, lazy reference index, and exported/API fingerprints remain separately authored compiler components; unknown semantic impact widens invalidation, and envelope inspection never replaces complete FS Diagnostic Compatibility. The detailed boundary and revisit triggers are defined by the [issue #17 research](../research/independent-fsharp-metadata-decoder.md).
