## Agent skills

### Issue tracker

Issues and PRDs live in GitHub Issues, accessed with the `gh` CLI. See `.agents/issue-tracker.md`.

### Triage labels

Use the default labels: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, and `wontfix`. See `.agents/triage-labels.md`.

### Domain docs

This is a single-context repo with root `CONTEXT.md` and `docs/adr/`. See `.agents/domain.md`.
